# HWP 웹 편집기

브라우저에서 한글 문서(**.hwp**, **.hwpx**)를 열고, 편집하고, 다시 저장하는 웹 문서 편집기입니다.
서버 없이 모든 처리가 브라우저 안에서 이루어집니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 정적 배포 파일(dist/) 생성
npm test           # 단위·왕복 변환 테스트
npm run e2e        # Chromium 에서 실제 편집·저장 흐름 확인
```

## 현재 기능 (1단계: 편집기 틀)

| 구분 | 내용 |
| --- | --- |
| 열기 | HWP 5.0(바이너리), HWPX(OWPML). 파일 선택 또는 끌어다 놓기 (`Ctrl+O`) |
| 저장 | HWPX(`Ctrl+S`), HWP(`Ctrl+Shift+S`). 형식 간 변환 저장 가능 |
| 글자 | 글꼴, 크기, 굵게/기울임/밑줄/취소선, 글자 색 |
| 문단 | 정렬(양쪽/왼쪽/가운데/오른쪽), 줄 간격, 여백·들여쓰기 표시 |
| 편집 | 한글 IME 입력, 문단 나누기/합치기, 강제 줄바꿈(`Shift+Enter`), 탭, 붙여넣기, 되돌리기/다시 실행 |
| 쪽 | 용지 크기·방향·여백을 반영한 화면 |
| 보존 | 표·그림·수식·각주·머리말 등 아직 편집하지 못하는 개체는 원본 데이터를 그대로 보존해 저장 |

## 구조

```
src/
  model/        공통 문서 모델 (글자/문단 모양, 스타일, 구역, 문단, 런)
  formats/
    hwpx/       HWPX 읽기/쓰기 (header.xml, section*.xml, content.hpf)
    hwp/        HWP 5.0 읽기/쓰기 (CFB 복합 파일, DocInfo/BodyText 레코드)
  editor/       편집기 (모델 ↔ DOM 렌더링/추출, 선택 위치 변환, 편집 연산, 되돌리기)
  ui/           도구 모음
  io/           파일 형식 판별, 열기/저장
  templates/    빈 문서 템플릿 (HWPX/HWP)
```

설계 원칙

- **원본 보존 우선**: 열어 둔 문서를 저장할 때 원본 패키지/스트림을 바탕으로, 바뀐 부분(글자·문단 모양, 본문)만 다시 씁니다.
  편집기가 모르는 요소는 XML 조각(HWPX)이나 레코드 트리(HWP)째로 들고 다니다가 그대로 되돌려 씁니다.
- **입력은 브라우저, 구조 편집은 모델**: 한글 조합 입력은 contenteditable 에 맡기고, 문단 나누기·서식 같은 구조적 편집은
  모델에 적용한 뒤 다시 그립니다.
- 길이 단위는 HWPUNIT(1/7200 인치)로 통일하며, HWPX `hp:switch` 의 case/default(2배 값) 규칙과
  HWP 문단 여백의 2배 저장 규칙을 따릅니다.

## 검증

- 단위/왕복 테스트: `npm test`
- 실제 문서 왕복 검사: `HWP_CORPUS=<폴더> npm test -- tests/corpus.test.ts`
  - 공개 테스트 문서 81개(한컴오피스로 작성된 HWP 36개, HWPX 45개)를 열고 같은 형식·다른 형식으로 저장한 뒤 다시 열어
    본문 텍스트와 개체 수가 같은지 확인 — 전부 통과
  - 저장된 158개 파일을 독립 도구로 검사 — HWPX 는 python-hwpx OWPML 스키마 검증, HWP 는 pyhwp·python-hwpx 파서로
    읽기 확인 — 전부 통과
- 한컴오피스에서 직접 열어 보는 시각 비교는 이후 단계에서 진행합니다.
